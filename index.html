💡 TCP / QUIC / WebSocket 三种协议至少启用一种，端口可相同（内部自动复用）
TCP over TLS 服务绑定地址；留空不启用 TCP
基于 UDP 的加密低延迟协议（需 TLS）；留空不启用
WSS 可穿透 HTTP 代理（需 TLS）；留空不启用
🔗 虚拟网络基础 ▾
CIDR 格式；网关为该网段首个可用 IP（10.26.0.0/24 → 网关 10.26.0.1）
留空允许所有 network_code 接入；填写后仅白名单内的才可组网
离线超过此时间将回收 IP；默认 86400（24 小时）
数据持久化
开启后重启不丢失 IP 分配记录，网络信息写入 network_control.db（推荐开启）
🗺️ 虚拟网段 & 接入密码 ▾
⚠️ v2 强制要求：每个网段必须配置对应的接入密码（network_secrets）。
客户端 network_code = 名称，password = 密码，缺一不可。
💡 密码要求：≥24 字符，含大写 + 小写 + 数字 + 符号至少 3 类，不含空格。
或使用 ≥32 字符的纯十六进制字符串。
名称（network_code） 网段（CIDR） 接入密码（password）
default 网段为必须项，不可删除；其他网段为独立隔离的虚拟局域网
🖥️ Web 管理界面 ▾
留空不启用 Web 管理界面；端口不可与 TCP/QUIC/WS 相同
⚠ 生产环境务必修改默认用户名密码！
🔒 TLS 证书 ▾
💡 不填时自动生成自签名证书；QUIC / WSS 协议必须使用 TLS
🔀 服务端互联（多节点集群） ▾
💡 多台 VNTS2 服务器组成集群时使用，单节点部署无需填写
格式：IP或域名:端口，如 server2.example.com:29873
